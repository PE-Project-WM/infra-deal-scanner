Corrections

Last updated 25 November 2026

If a figure, description, sector or ownership note is wrong, please say so. Corrections make the ranking better for everyone.

How to ask

Contact opening an issue on GitHub (public; do not include personal details there). Include the company name or number, what is wrong, and where the right information can be checked (for example a filed accounts page or an announcement).

What happens next

Each request is checked against the source. Where the site is wrong, the figure is corrected in a record of hand corrections, the change is noted, and the site is rebuilt, usually within a week. If a request is not accepted, the reply says why.

Companies

Companies cannot pay to be included, excluded or moved. A company that believes it is misdescribed can ask for a correction like anyone else.
