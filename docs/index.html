UK digital infrastructure: the ten best-fit companies

A screen of every UK fibre, wireless, data-centre and network-services company that files full accounts, ranked against a written investment thesis. It reads public Companies House filings each week and explains every change in the ranking.

Each bar is a bundle of six strands, one per scoring criterion, so you can see why a company ranks where it does. How easy a company would be to buy is shown separately and never added to the score. Select a company for its numbers.

    How it works

    Five steps, run on GitHub's servers with Python. The ranking and this page rebuild themselves every week.

    1. Write the thesisA testable claim about the sector, with kill criteria, turned into a criteria file.
    2. Pull the registerCompanies House bulk data filtered by industry code, status and accounts type.
    3. Read the accountsDigital tags first, the text of the accounts as a backup, with a currency check.
    4. Clean and checkOwners traced through parent companies, duplicates merged, off-thesis firms removed.
    5. Score and explainSix weighted criteria; each week's moves explained from the points that changed.
